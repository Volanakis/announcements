# ΔΑΠ-ΝΔΦΚ Σάμου — ανακοινώσεις εφαρμογής

Το αρχείο `announcements.json` διαβάζεται από την εφαρμογή. Οι αλλαγές φαίνονται σε 1–2 λεπτά, χωρίς νέο APK.

## Πώς προσθέτω ανακοίνωση
Άνοιξε το `announcements.json` στο github.com → ✏️ Edit → πρόσθεσε νέο αντικείμενο **στην αρχή της λίστας** → Commit changes.

```json
{
  "id": "dsp-5",
  "date": "2026-10-09",
  "tag": "Προτάσεις ΔΣ",
  "title": "Τίτλος",
  "summary": "Σύντομη περίληψη (1-2 γραμμές).",
  "body": "Παράγραφος 1.\n\nΠαράγραφος 2.\n\n- στοιχείο λίστας\n- άλλο στοιχείο"
}
```

- `id`: μοναδικό, χωρίς κενά (π.χ. `dsp-5`).
- `date`: ΕΕΕΕ-ΜΜ-ΗΗ.
- `body`: `\n\n` = νέα παράγραφος, γραμμές που αρχίζουν με `- ` γίνονται λίστα.
- Προσοχή στα κόμματα ανάμεσα στα αντικείμενα και στα εισαγωγικά. Έλεγξε το αρχείο σε https://jsonlint.com πριν το αποθηκεύσεις· αν είναι λάθος, η εφαρμογή κρατά τις προηγούμενες ανακοινώσεις.

Το αποθετήριο είναι δημόσιο: μην γράφεις προσωπικά δεδομένα. Δικαίωμα επεξεργασίας να έχουν μόνο όσοι ανεβάζουν ανακοινώσεις (Settings → Collaborators), με ενεργή επαλήθευση δύο βημάτων.
